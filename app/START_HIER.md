# Layer 1.4 – Photo First

Node.js LTS installieren. Im App-Verzeichnis `npm ci` und `npm run dev` ausführen oder Windows_Start.cmd nutzen. Produktion: `npm test`, `npm run build`, anschließend `dist/` samt Modellen und Lizenzhinweisen veröffentlichen.

Echte Fotos wählen, bestätigen, optional lokal freistellen, Original vergleichen und Kleidungsdaten speichern. Die optionale Cloud-KI analysiert nur Metadaten und empfiehlt Outfits aus vorhandener Kleidung. Keine generative Bild-Erstellung. Alte Bilder, Originale und Historien bleiben erhalten. Vor Gerätewechsel JSON-Backup sichern. Details in README.md und docs/AUDIT_1.4.md.
